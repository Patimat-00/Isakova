# Currency Converter

**Автор:** Патимат Исакова

## Описание
Простое GUI-приложение для конвертации валют с использованием внешнего API (exchangerate-api.com), сохранением истории в JSON и возможностью загрузки.

## Требования
- Python 3.x
- Библиотеки: requests, tkinter (входит в стандартную поставку)

## Установка
1. Установите зависимости:
   pip install -r requirements.txt

2. Получите API-ключ на exchangerate-api.com и вставьте его в переменную API_KEY в main.py.

## Запуск
python main.py

## Использование
1. Выберите исходную и целевую валюту.
2. Введите сумму (только положительное число).
3. Нажмите «Конвертировать».
4. Результат появится ниже. История операций отображается в таблице.

## Примеры тестов
- Ввод отрицательной суммы — ошибка.
- Ввод текста вместо числа — ошибка.
- Отсутствие интернета — сообщение об ошибке.
- Загрузка истории при запуске приложения.
